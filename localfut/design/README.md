# Launcher design

Generated with the built-in imagegen tool, then implemented as native C# WinForms controls. The mockup is a design reference, not an image rendered behind the UI.

## Final edit prompt

Use case: ui-mockup
Edit the supplied launcher mockup into a darker, cleaner, sleeker Windows desktop app. Preserve its useful controls, labels and hierarchy, but simplify the presentation.
Use matte charcoal background (#15171b), slightly lifted dark cards (#1d2026), thin low-contrast slate borders, off-white text and muted secondary text. One restrained blue accent (#608de8) on the Start button and tiny status details. No gradients, glow, neon, photos, oversized icons, thick outlines or busy decoration.
Make the title modest and refined (not huge/bold), reduce boxed sections, remove the football titlebar logo, keep a small native titlebar. Keep Settings with a subtle Material gear icon. Game installation is a compact card with file icon, "Select FIFA21.exe to get started", Browse button and small "Saved on this PC only".
Primary "Start LocalFUT" with Material play icon. Quiet secondary "Stop services" button. Status starts "Ready to start" with a small neutral dot, not a checkmark and no fake progress; explanatory text plus an empty thin progress track.
Instructions should be a slim borderless three-column row with small step numbers, not large rings. A clean compact Activity section with subdued monospaced logs and "Open logs" action. Keep all text readable with practical spacing.
Flat front-on screenshot, single window, no surrounding scene. A realistic design readily implementable in native C# WinForms.
