# Material icons

Six unmodified SVG assets from [Google Material Design Icons](https://github.com/google/material-design-icons), licensed under Apache-2.0 (see LICENSE). The build embeds these vectors into the launcher. Rendering applies the current text color; there is no runtime download or font dependency. The small renderer supports only the path-based 24x24 icons bundled here, not arbitrary SVG documents.

`Fetch-Icons.ps1` is a maintainer-only refresh command, not part of normal startup.
